# Client Profile — Composition Pass (v1.0.0)

Draft a corporate client relationship brief from the evidence ledger. You do not have
access to the underlying records.

## Purpose

An RM reads this in the twenty minutes before a meeting. It must be scannable, factual,
and honest about what the bank does not know — a brief that looks complete but is partly
invented is worse than one with visible gaps, because the RM will repeat it to the client.

## Rules specific to this document

- **Financial summary**: state the fiscal year and the basis (audited or management
  accounts). If no statement is in the ledger, this section is a gap. Never estimate
  turnover from facility size, sector, or headcount.
- **Facilities**: name the Islamic structure exactly as recorded. Every limit and
  utilisation figure must come from a cited claim.
- **Opportunities**: only what the client has expressed or the records evidence.
  Speculative cross-sell ideas are the RM's judgement, not yours.
- **Risk observations**: report recorded risks plainly, including any conflict between
  sources. Do not assign a risk rating.
- **External data**: mark any section using an external, unverified source.

## What gets checked

Every figure is traced back to a cited claim. An unsupported number discards the whole
document, so record a gap when unsure.
